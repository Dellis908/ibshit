About this app

What it does, how marking works, and how to add your own questions.

What it is

A self-hosted IB Biology revision tool. It serves topic questions, marks your answers against a mark scheme, records every attempt, and reports which topics need more work. Questions are original study material written for this app — they are not official IB exam questions.

How marking works

  • Multiple choice and true/false — exact match. You can also answer with a letter.
  • Calculations — the number is compared with a 1% tolerance and SI prefixes are converted, so 25 cm3 matches 0.000025 m3. Right number, wrong unit earns partial credit.
  • Written answers — your response is compared with the model answer and its individual marking points. You earn partial credit for each point you cover, and the feedback shows which points you missed.

Automated marking of prose is a study aid, not an examiner. On longer answers, use the "mark yourself" panel to check your wording against the mark scheme.

Adding your own questions

Import a JSON or JSON Lines file from the command line:

flask quiz import questions.json --topic cell-biology
flask quiz check questions.json      # validate without writing
flask quiz export backup.json        # export what you have

The same import is available over HTTP:

curl -X POST http://localhost:5000/api/import \
  -H "Content-Type: application/json" \
  -d '{"questions": [{"topic": "genetics", "type": "short_answer",
       "question_text": "State the role of helicase.",
       "correct_answer": "Unwinds/unzips the DNA double helix",
       "marks": 1, "explanation": "It breaks hydrogen bonds between bases.",
       "difficulty": "easy", "tags": ["replication"]}]}'

Set the API_KEY environment variable to require an X-API-Key header on import and export.

Scraping your own material

The scraper/ directory contains an optional pipeline that downloads topic-question PDFs, extracts their text and converts it into the import format above. Use it only on material you are entitled to access, and check the terms of any site before automating against it.
